# 03. Necessary graphics — графики CH-01..CH-25

> Роль: Data Analyst (NAFA). PNG-файлы лежат в `docs/assets/charts/`, рядом с каждым — метаданные `CH-xx.json` для Prompt Engineer и интерфейса. Код: `da_scripts/analytics/charts.py`.

## 1. Соответствие общим требованиям (раздел 5.1 ТЗ)

| Требование | Как выполнено |
|---|---|
| PNG 1600×900, 16:9, 200 dpi | `FIGSIZE=(8, 4.5)`, `DPI=200` в `charts.py` |
| Русский язык, единицы в осях | да (например «выручка, млрд руб (лог)», «% годовых») |
| Заголовок формулирует вывод | да (например «Расхождение лент клиентов: PD@5 = … (цель ≥ 0.40)») |
| Источник и as_of внизу | подпись источника на графике + `as_of` в `CH-xx.json` |
| Дальтонизм-безопасная палитра | Okabe-Ito (`PALETTE`), не только цвет: подписи значений |
| Имя файла | `CH-xx_<slug>.png` |
| Метаданные рядом | `CH-xx.json`: `id`, `title`, `metric_ids`, `as_of`, `takeaway` (≤ 25 слов), `alt_text`, `source` |
| Код одной командой | графики строятся автоматически в `python -m analytics.run_all`; выборочно — `charts.build_charts(ctx, priority=..., only=[...])` |

## 2. Реестр графиков

## 3. Как воспроизвести

```
python -m analytics.run_all --data-dir real_data --out-dir out
```

Все доступные графики строятся автоматически (P0 + P1), каждый — с JSON-метаданными. Выборочно:

```python
from analytics.charts import build_charts
build_charts(ctx, priority="P0", only=["CH-06", "CH-14"])
```

Появление `rate_fact.csv`/`rate_forecast.csv` в папке данных автоматически включает CH-08 при следующем прогоне.
