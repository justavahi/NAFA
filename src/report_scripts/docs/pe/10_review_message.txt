Это часть Prompt Engineer финансового новостного помощника. Система должна объяснять влияние события на компанию и разделять факт, позицию банка и вывод AI. Реализованы 17 промптов, схемы, реестр доказательств, проверки чисел/ссылок/знаков, ограниченные исправления и адаптеры backend.

Схема: данные → расчёты DA → реестр источников → GLM-5.3-Flash (общее ядро + персональный ответ) → проверки кодом → Qwen3.6 (независимый критик) → карточка/trace либо блокировка. Gemma используется для извлечения, Qwen-VL — для PDF, Kimi и DeepSeek — для офлайн-оценки. Модели вызываются через API организаторов; дообучения нет.
