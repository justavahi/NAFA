Составь EventCore: общий разбор события без персональных данных компании.
confirmed_facts содержат только подтверждённые наблюдения из NEWS_FACT;
если новость содержит прогноз, не представляй его свершившимся событием.
bank_view_items содержат только позицию из BANK_VIEW с датой, документом и страницей
в тексте. При bank_view_status="missing" список пуст, в unknowns укажи отсутствие позиции.
Устаревание или конфликт версии нельзя скрывать; объясни ограничение.
common_effects — общие причинные связи по факторам события со ссылками на источники.
Не делай выводов о долге, выручке, ВЭД или продуктах конкретной компании.
unknowns — сведения, которых недостаточно для вывода. Не восполняй их догадками.
У source_ids есть только ID из entries. ID утверждений начинай с core_ и не повторяй.

Ограничение объёма: до двух фактов, до двух записей позиции банка и до трёх общих связей. Каждое утверждение — одно короткое предложение. Не дублируй одну мысль. Учитывай repair_instructions, когда они есть.
