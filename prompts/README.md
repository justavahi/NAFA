# Промпты NAFA

Все 17 задач из ТЗ BA реализованы. Активные файлы, версии, модели, схемы,
ограничения и ссылки на тестовые случаи задаёт `manifest.json`.
Общие правила находятся в `common_v2.txt`; предыдущие версии сохранены
для воспроизведения экспериментов. Few-shot примеры в запросы не встроены.

`pe.prompts.prepare_request` проверяет вход и формирует запрос с JSON-схемой.
`pe.tasks.run_task` исполняет отдельную задачу; `pe.pipeline.run_case` собирает
карточку и запускает независимого критика. Внешний текст оборачивается
как недоверенные данные. Вычисления DA передаются готовыми значениями.

Результаты реальных вызовов и границы проверки: [отчёт](../docs/pe/evaluation/acceptance_summary.md).
Команды запуска и интеграция: [README](../README.md).
