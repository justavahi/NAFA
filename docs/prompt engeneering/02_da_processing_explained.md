# Как объяснять расчёты DA

Источник: закреплённый каталог и паспорта в `reference/`; ревизии перечислены в `reference/snapshot.json`. Все числа считает код DA, PE формулирует объяснение.

## Метрики

Покрыты все 54 P0-метрики каталога и остальные признаки F/G/E. Остальные группы приведены в P0-объёме. Вход в промпт всегда включает готовое значение, единицу, дату и ID доказательства; пропуск остаётся NULL.

| ID и название | Что это | Как сказать пользователю | Как использовать | Чего нельзя утверждать |
|---|---|---|---|---|---|
| F-01 Крупный бизнес и масштаб | is_large = 1[REVENUE_COMPANY >= 15 млрд ₽]; rev_log10 = log10(REVENUE_COMPANY). Единицы измерения REVENUE_COMPANY проверить по данным | Масштаб компании по выручке | FM-21 (индекс уязвимости к ставке), FM-24 (ScaleFactor), фильтры ленты | Не называть компанию крупной до подтверждения единиц выручки |
| F-02 Позиция в отрасли (прокси доли рынка) | share_okved = REVENUE_c / SUM(REVENUE_j по тому же 2-значному ОКВЭД); pctl = перцентиль выручки внутри отрасли (и внутри региона). Показывать как «доля в выборке банка», не как рыночную долю | Положение среди клиентов банка своей отрасли | FM-21 (вес масштаба), FM-24 (ScaleFactor) | Это доля в выборке банка, а не рыночная доля |
| F-03 Отрасль и профиль отрасли | okved_div = первые 2 цифры MAINOKVED_CODE; section = A..U; sector_profile = SP-01..SP-15 по okved_to_sector_profile.csv | Отраслевой профиль помогает выбрать каналы влияния | Вся отраслевая цепочка: prior в E-14, миксы G-04, радар CH-06, CH-23 | Отрасль не доказывает наличие конкретного договора |
| F-04 Возраст и стадия развития | age_bucket = COMPANY_AGE_YEARS_GRADATION; stage = ECO_MARK_LABEL; growth_flag = 1 для стадий роста/запуска (словарь значений получить из данных) | Возраст и стадия развития | Передать F-04 как готовое значение с единицей категория, флаг и source_ids | Не выходить за готовые расчёты и видимые данные |
| F-05 Численность персонала (согласованная) | headcount_mid = среднее середин градаций ФНС и СПАРК; conflict = 1, если градации не пересекаются; rev_per_emp = REVENUE / headcount_mid | Численность персонала (согласованная) | Передать F-05 как готовое значение с единицей чел., ₽/чел. и source_ids | Не выходить за готовые расчёты и видимые данные |
| F-06 Форма собственности и тип организации | OKFS_NAME, ORG_TYPE; is_state_related = 1 для государственной/муниципальной собственности (словарь уточнить по данным) | Форма собственности и тип организации | Передать F-06 как готовое значение с единицей категория, флаг и source_ids | Не выходить за готовые расчёты и видимые данные |
| F-07 География присутствия | home_region = REGION; home_city = CITY; presence_regions = {REGION} + {RC_NAME связанных физлиц}; geo_entropy = -SUM(p_r ln p_r) | География присутствия | Передать F-07 как готовое значение с единицей множество, число и source_ids | Не выходить за готовые расчёты и видимые данные |
| F-08 Продуктовый профиль в банке | Вектор из 7 флагов (RKO, GAR, LOA, LEA, DEP, ZPP, FACTORING); breadth = SUM(флагов) | Известные продукты в данном банке | E-01, E-02, E-09, E-10 (own-компоненты экспозиций), продуктовые офферы | NULL не означает отсутствие; неизвестны суммы и продукты других банков |
| F-09 Внешнеторговая вовлечённость | fts_flag = FTS_FLAG; fts_country = FTS_COUNTRY_NAME; fx_hint = маппинг страна -> валюта (например КНР -> CNY). Направление (экспорт/импорт) в данных отсутствует | Есть признаки внешнеторговых расчётов | E-03, E-12, событие FX | Нельзя угадывать экспорт/импорт, валюту контракта и знак риска |
| F-10 Статус клиента | cl_type: действующий / потенциальный. У потенциальных продукты банка неизвестны, а не «отсутствуют» | Действующий или потенциальный клиент | Офферы (только действующим), интерпретация лент, CH-06 | У потенциального клиента продуктовые сведения могут отсутствовать |
| F-11 Структура группы компаний | group_size = число компаний с одним GROUP_ID; group_revenue = SUM(REVENUE); group_div_hhi = SUM(доля_отрасли^2) | Структура группы компаний | Передать F-11 как готовое значение с единицей компаний, ₽, 0..1 и source_ids | Не выходить за готовые расчёты и видимые данные |
| F-12 Признак ключевого собственника (NEGATIVEMARK) | Использовать как есть, но название поля и описание расходятся: семантику подтвердить у организаторов | Признак ключевого собственника (NEGATIVEMARK) | Передать F-12 как готовое значение с единицей флаг и source_ids | Не выходить за готовые расчёты и видимые данные |
| F-13 Полнота и шумность данных | completeness = SUM(w_k * 1[поле_k не пусто]) / SUM(w_k) по ключевым полям; noise_flags = конфликт ФНС/СПАРК, нулевая выручка, аномальные значения | Насколько полон и согласован профиль | FM-20 (уверенность карточки), Q-17 (устойчивость к пропускам), фильтры качества ленты | Полнота не гарантирует истинность каждого поля |
| G-01 Платёжные обороты (вход/выход) | in = SUM(PAY_AMT \| BENEFICIARY = c); out = SUM(PAY_AMT \| PAYER = c); net_ratio = in / (in + out) | Объём известных платежей за предоставленный период | E-13, FM-22, CH-21, базовая линия FM-24 | Не называть его всей выручкой или расходами компании |
| G-02 Число контрагентов | n_cust = число уникальных PAYER для c; n_sup = число уникальных BENEFICIARY для c | Число видимых контрагентов | E-13 (поправка на малое число контрагентов), CH-04 | Наблюдается только сеть внутри набора данных |
| G-03 Концентрация контрагентов (HHI) | HHI_in = SUM(s_i^2), s_i = PAY_AMT_i / in; HHI_out аналогично по out | Насколько платежи сосредоточены на нескольких партнёрах | E-13 (own_cpty = 0.6·HHI_in + 0.4·HHI_out), CH-05 | HHI не является вероятностью дефолта |
| G-04 Отраслевой микс контрагентов | mix_cust[s] = SUM(PAY_AMT(j->c) * 1[SP(j)=s]) / in; mix_sup[s] = SUM(PAY_AMT(c->j) * 1[SP(j)=s]) / out. Клиенты = плательщики в адрес c, поставщики = получатели от c | Какие отрасли представлены среди поставщиков и покупателей | E-04..E-07 (chain), FM-22 (веса рёбер шока), CH-21 | Не присваивать связь конкретной компании без подтверждённого ID |
| G-05 Региональный микс контрагентов | Аналог G-04 по REGION контрагентов | Региональный микс контрагентов | Передать G-05 как готовое значение с единицей доли и source_ids | Не выходить за готовые расчёты и видимые данные |
| G-06 Ключевые контрагенты (top-k) | Top-k по PAY_AMT с их SP, регионом и CL_TYPE; k = 5 | Ключевые контрагенты (top-k) | Передать G-06 как готовое значение с единицей список и source_ids | Не выходить за готовые расчёты и видимые данные |
| G-07 Доля внутригрупповых платежей | SUM(PAY_AMT между компаниями одного GROUP_ID) / (in + out) | Доля внутригрупповых платежей | Передать G-07 как готовое значение с единицей 0..1 и source_ids | Не выходить за готовые расчёты и видимые данные |
| G-08 Центральность в платёжной сети | PageRank и взвешенная степень на графе платежей | Центральность в платёжной сети | Передать G-08 как готовое значение с единицей число и source_ids | Не выходить за готовые расчёты и видимые данные |
| G-09 Связность через физических лиц | Число компаний, делящих хотя бы одно SYNTHETIC_F с c | Связность через физических лиц | Передать G-09 как готовое значение с единицей шт. и source_ids | Не выходить за готовые расчёты и видимые данные |
| G-10 Средний чек и частота платежей | avg_ticket = SUM(PAY_AMT) / SUM(PAY_CNT); freq = SUM(PAY_CNT) | Средний чек и частота платежей | Передать G-10 как готовое значение с единицей ₽, шт. и source_ids | Не выходить за готовые расчёты и видимые данные |
| E-01 Собственная процентная нагрузка (долг) | own_rate_debt = 1 - (1 - 0.6*LOA)(1 - 0.3*LEA)(1 - 0.3*FACTORING) (noisy-OR; веса стартовые, в config) | Чувствительность заёмного финансирования к ставке | `eps_RATE` (own), E-15, FM-21, CH-06 | Нет размера долга — нет суммы переплаты |
| E-02 Собственная депозитная выгода | own_rate_dep = 0.6 * DEP_MARK | Возможная выгода по депозитам при высокой ставке | `eps_RATE` (own = max(E-01, E-02)), E-15, CH-06 | Нет остатков и условий — нет расчёта дохода |
| E-03 Собственная валютная экспозиция | own_fx = 0.8 * FTS_FLAG. При отсутствии FTS_FLAG компонент пуст, а не ноль | Связь бизнеса с валютными расчётами | `eps_FX`, событие FX, FM-15(б) | Без направления сделки знак эффекта неизвестен |
| E-04 Экспозиция к инфляции затрат | Компонент по фактору INFL: только отраслевой prior и цепочка поставок (own не определён) | Экспозиция к инфляции затрат | Передать E-04 как готовое значение с единицей 0..1 и source_ids | Не выходить за готовые расчёты и видимые данные |
| E-05 Экспозиция к топливу и энергии | Компонент по фактору ENERGY: prior отрасли + цепочка | Экспозиция к топливу и энергии | Передать E-05 как готовое значение с единицей 0..1 и source_ids | Не выходить за готовые расчёты и видимые данные |
| E-06 Экспозиция к ценам сырья | Компонент по фактору COMMOD: prior отрасли + цепочка | Экспозиция к ценам сырья | Передать E-06 как готовое значение с единицей 0..1 и source_ids | Не выходить за готовые расчёты и видимые данные |
| E-07 Экспозиция к потребительскому спросу | Компонент по фактору DEMAND: prior отрасли + клиентская цепочка mix_cust | Экспозиция к потребительскому спросу | Передать E-07 как готовое значение с единицей 0..1 и source_ids | Не выходить за готовые расчёты и видимые данные |
| E-08 Экспозиция к рынку труда | own_labor = clip(headcount_mid / медиана_отрасли) * (0.7 + 0.3*ZPP_MARK) | Экспозиция к рынку труда | Передать E-08 как готовое значение с единицей 0..1 и source_ids | Не выходить за готовые расчёты и видимые данные |

## Глоссарий и тон

ЛПР — руководитель, принимающий решение; ДКП — денежно-кредитная политика; ОФЗ — облигации федерального займа; п.п. — разность процентных ставок; г/г — сравнение с тем же периодом прошлого года; м/м — с прошлым месяцем; н/н — с прошлой неделей; ВЭД — внешнеэкономическая деятельность; экспозиция — чувствительность к фактору; prior — исходная отраслевая гипотеза; NULL — данных нет; MMR — отбор с ограничением повторов.

Тон: короткие деловые предложения; сначала наблюдение, затем механизм и связь с компанией. Действия — вопросы для проверки и варианты обсуждения. Прогноз сопровождается датой и горизонтом. Каждая карточка содержит оговорку «Не является индивидуальной инвестиционной рекомендацией».
