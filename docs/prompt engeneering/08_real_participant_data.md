## Результаты изменения подхода

Структурированный кандидат и отдельный протокол реализованы. Неудачная попытка
v5 сохранена в [первом пилоте](evaluation/improvement_v1/summary.md); исправление
формата v6 — во [втором пилоте](evaluation/improvement_v2/summary.md).
На двух оценённых синтетических случаях v6 получил 4.0/4.0, baseline — 3.8/4.0
по одинаковой новой рубрике. Третий кандидат остановился на тайм-ауте критика.
Полного сравнения двумя судьями и подтверждения общего прироста нет.
Закрытые validation/test не оценивались, production продолжает использовать v4.

После подключения CSV выполнен отдельный ограниченный сквозной A/B на одном
профиле заёмщика. Событие — атрибутированная публикация из предоставленного
корпуса DOC-07 о пересмотре прогноза; факт её публикации не является независимым
подтверждением экономического прогноза. Релевантность и знак RATE считает DA;
предварительная уверенность ограничена политикой до критики, не вероятностью
бизнес-исхода. Обе версии прошли проверки и получили по 3.8 по новой рубрике.

Это отрицательный результат гипотезы «одной структуризации достаточно» на этом
примере. Медиана 4.5 на независимых задачах **не подтверждена**. Судья также
ограничил mechanisms за единственный канал, хотя вход поддерживает один и
рубрика допускает это: такой результат требует ручной калибровки, а не
придумывания второго канала ради балла. Свободных оценок людей не подставляем.

Следующие содержательные проверки: точное выделение относящихся к событию
фрагментов (в исходном абзаце есть также бюджетный фон), явное описание роли
пользователя вместо одного кода PER-03, слепое человеческое сравнение и набор
разных реальных событий/клиентских групп. Смена рубрики потребует повторного
замера baseline; существующий закрытый тест остаётся закрытым.

## Воспроизведение

```bash
uv sync --dev --extra backend --extra da
uv run --extra backend python scripts/download_participant_data.py
uv run python scripts/prepare_da.py
uv run --extra da python scripts/process_participant_data.py
uv run --extra da python scripts/real_profile_smoke.py prepare --out out/real_profile_smoke_v1
uv run --env-file .env --extra backend --extra da python scripts/real_profile_smoke.py run --out out/real_profile_smoke_v1
```

Если локальный snapshot или выходная папка уже есть, скрипт сохранит их и
попросит новую папку. Демо-графики и качество с саморазметкой DA отключены.
SHA256 исходных файлов, агрегатов и неизменяемый протокол сохранены локально.
Повторные вызовы моделей не нужны, чтобы посмотреть готовые результаты.
Для прогона с нуля нужны Git-объекты закреплённой ветки DA и доступ к разрешённому
API. Короткая проверка ограничена 16 обращениями, 80 000 дополнительными
токенами и 180 секундами на обращение. Общая база и серверный рублёвый предел
сохраняются. Сырые CSV не являются размеченными ответами для SFT.
