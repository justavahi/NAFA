## 0. Цель роли и критерии успеха

**Цель:** сделать так, чтобы данные (клиенты, платежи, новости, аналитика Альфы, макроряды) попадали в систему корректно, повторяемо и с сохранением связи с первоисточником, а агент NAFA мог вызывать их как инструменты. Кроме того, Backend отвечает за оркестратор агента, шлюз к LLM, API, трассировку, безопасность и сдачу (Docker, README и т.д.).

**Критерии успеха роли (из критериев кейса):**

| Критерий | Что должен обеспечить Backend |
|---|---|
| C04 | Дедупликация, нормализация, ссылки на первоисточник у каждой записи |
| C05 | Приём «чужой» новости (текст или URL) без правок кода |
| C06, C09, C10 | Работающий сквозной путь и интерфейс (если отдельный исполнитель интерфейса не назначен, UI-01..UI-09 из раздела 5.7 справочника входят в зону Backend) |
| C07 | Источники и справочники подключаются конфигурацией |
| C11 | Оркестратор: план, инструменты, общий контекст, самопроверка |
| C12 | Полная трассировка каждой карточки |
| R04 | Шлюз LLM с маршрутизацией, кэшем, токен-счётчиком и «сторожем бюджета» |
| R06 | Роли доступа, журналирование вызовов, защита от инъекций |

## 2. Рекомендуемый технический набор (допущение, можно заменить обоснованно)

| Слой | Рекомендация | Почему |
|---|---|---|
| Язык | Python 3.11+ | Весь стек данных и LLM-клиентов |
| API | FastAPI + автогенерация OpenAPI | Требуется описание API; быстро |
| Хранилище | SQLite (состояние приложения) + DuckDB (аналитика CSV и платежей) либо Postgres в Docker | Не нужен внешний сервис, воспроизводимо у жюри |
| Поиск | Базовый вариант без эмбеддингов: SQLite FTS5 или BM25 (`rank_bm25`) + LLM-реранжирование; эмбеддинги подключаются только после разрешения организаторов (OQ-01) | RSK-03 |
| Парсинг | `feedparser` или `lxml`/`httpx` с терпимым режимом разбора, `selectolax`/`BeautifulSoup` для HTML, `requests` | RSS РБК и Интерфакса имеют отклонения от стандарта (SRC-03, SRC-04) |
| Подготовка текста | `pymorphy3` (лемматизация), `NLTK` (стоп-слова), `Sumy` (экстрактивная суммаризация), `Gensim` или TF-IDF в `scikit-learn` (векторизация) | Классический конвейер B0 (раздел 8.5 справочника); допустимость классических библиотек уточняется в OQ-01 |
| Замеры | `time`, `datetime`, `tracemalloc` | Время и память на этапах конвейера для Q-12 и Q-24 |
| Очередь/расписание | `APScheduler` или `cron` внутри контейнера | Достаточно для прототипа |
| UI | Streamlit или Gradio (быстрый старт), либо лёгкий React | Интерфейс может быть на любых технологиях (кейс) |
| Запуск | `docker compose up`, одна команда; lock-файлы (`uv.lock`/`poetry.lock`/`requirements.txt` с хэшами) | Формат сдачи кейса |

### 4.2 Схема `Document` (новости и аналитика после нормализации)

```json
{
  "doc_id": "sha1(canonical_url)",
  "source_id": "SRC-03",
  "kind": "news",
  "title": "…",
  "url": "…",
  "canonical_url": "…",
  "published_at": "2026-10-20T17:06:00+03:00",
  "fetched_at": "2026-10-20T17:10:12+03:00",
  "language": "ru",
  "category": "…",
  "snippet": "…",
  "text": null,
  "tier_weight": 0.85,
  "content_hash": "…",
  "cluster_id": null,
  "stale": false
}
```

### 4.3 Схема `Chunk` (корпус Альфы после VLM)

```json
{
  "chunk_id": "DOC-07-p1-b3",
  "doc_id": "DOC-07",
  "page": 1,
  "block_type": "text | table | chart_caption | chart_estimate",
  "text": "…",
  "numbers": [{"value": 14.0, "unit": "% годовых", "subject": "ключевая ставка", "date": "2026-09-11"}],
  "as_of_date": "2026-09-11",
  "extraction_model": "Qwen3-VL-30B-A3B-Instruct",
  "extraction_confidence": 0.0,
  "needs_manual_check": true
}
```

Правило: числа из графиков без подписей получают `block_type = chart_estimate` и не попадают в факты.

### 4.9 Практики сбора

Порядок выбора способа (по статье на Хабре о парсинге российских СМИ, раздел 7.4 справочника):

| Шаг | Способ | Когда |
|---|---|---|
| 1 | Официальный API или RSS | Всегда первым (SRC-01, SRC-02, SRC-03, SRC-04, SRC-16) |
| 2 | Внутренний JSON-запрос сайта (вкладка Network в браузере) | Если API нет, а условия использования это не запрещают |
| 3 | HTML-разбор (`BeautifulSoup`, `selectolax`) | Статичные страницы; селекторы выносятся в конфигурацию, так как вёрстка меняется |
| 4 | Браузерная автоматизация (Playwright, Selenium) | Только для динамических страниц и только при разрешающих условиях |

Дополнительно: повторы при ошибке (не более 5, с растущей паузой); если выдача ограничена по числу страниц, период режется на отрезки (у «Коммерсанта» 100 страниц на запрос, отрезок 31 день); результат каждого запуска пишется в `ingestion_log`. Ротация прокси и обход защиты от роботов не применяются: сайты, которые не отдают данные штатным способом, заменяются другими источниками или синтетическими новостями (RSK-10, RSK-15).
